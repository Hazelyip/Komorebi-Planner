# 🌿 Komorebi Planner

> A minimalist personal planning application inspired by the Japanese concept of 「木漏れ日」 — helping users organize tasks, build habits, and create meaningful daily routines.

---

## Overview

**Komorebi Planner** is a minimalist personal planning application designed to help users manage tasks, track habits, and organize their daily lives in a calm and intuitive way.

The name comes from the Japanese word **「木漏れ日」(Komorebi)**, describing sunlight filtering through trees. It represents small but meaningful moments in everyday life.

Unlike traditional productivity tools that focus only on efficiency and completion, Komorebi Planner focuses on:

- 🌱 Sustainable daily improvement
- 📝 Personal reflection
- 📅 Intentional planning
- ⚖️ Balance between productivity and well-being

The goal is to create a peaceful digital space where users can plan their future while appreciating their present.

## Features

- ✅ Task management
- 📅 Daily and weekly planning
- 🌱 Habit tracking
- 📝 Personal notes and reflections
- 🎨 Minimalist and responsive design
- ⚡ Simple and lightweight user experience

## 概要

**Komorebi Planner（木漏れ日プランナー）** は、日々のタスク管理、習慣形成、生活設計をサポートするミニマルな個人向けプランニングアプリです。

名前の由来である **「木漏れ日」** は、木々の間から差し込む柔らかな光を意味します。

本アプリは、単なる「効率化ツール」ではなく、

- 🌱 小さな成長の積み重ね
- 📝 日々の振り返り
- 📅 意識的な時間管理
- ⚖️ 生活と目標のバランス

を大切にした、新しいプランニング体験を提供することを目指しています。

忙しい毎日の中でも、自分自身のペースで未来を設計できる、静かで心地よいデジタル空間を作ることが本プロジェクトの目的です。

## 项目介绍

**Komorebi Planner（木漏れ日计划）** 是一款以「平静、高效、可持续成长」为理念设计的个人规划应用。

项目名称来源于日语 **「木漏れ日（Komorebi）」**，意为“透过树叶洒落的阳光”。

相比传统强调任务完成率和效率提升的生产力工具，Komorebi Planner 更关注：

- 🌱 长期习惯培养
- 📝 日常反思记录
- 📅 有意识的时间规划
- ⚖️ 工作、学习与生活之间的平衡

希望通过一个简洁、舒适的数字空间，帮助用户更好地管理自己的时间，并持续记录个人成长过程。

## 主要功能

- ✅ 任务管理
- 📅 日计划 / 周计划
- 🌱 习惯追踪
- 📝 日记与反思记录
- 🎨 简洁美观的响应式界面
- ⚡ 快速流畅的使用体验
